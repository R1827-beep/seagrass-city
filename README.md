# 海草床退化模拟：一座城市的选择 🌊

一个严肃向的生态教育互动模拟：你是一位中国沿海城市的决策者，1975 → 2025，整整 50 年。

在真实的历史浪潮中做出每一次建设抉择——围填海、深水港口、虾塘养殖、重工业区……经济的账很好算，而海面之下，海草床正悄然消失。

## ✨ 特色

- **双视角舞台**：城市天际线 ↔ 水下海草床，随时切换（快捷键 `V`），所有变化实时绘制
- **真实的 50 年**：时代指令取材真实历史（深圳填海、"工业立市"……）， GDP 复利、污染累积、政策与环境的**响应时滞**全部建模
- **15+ 设施**：工业、民生、环保三类设施，各有工期与生态代价——施工时能看到建筑贴图从下往上"长"出来
- **城市评级与称号系统**：每 5 年评定三档等级 + 14 种特色称号（创新引领城市、生态文明标杆……），附带真实奖励与加成
- **三条 Game Over 斩杀线**：经济崩溃 / 生态灾难 / 发展失衡——对应真实发生过的悲剧（如广西合浦儒艮保护区 7 年间海草床从 267 公顷退化到 0.1 公顷）
- **决策档案库**：你的每一次抉择被后台记录，历史事件的真相由你在档案库中亲手揭开
- **生态修复线**：2020 年后解锁污水处理厂、海草床修复工程、禁渔区—— GB/T 41339.4-2023 已发布，修复是可能的
